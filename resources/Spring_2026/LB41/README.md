**Speaker**: Shane Elipot (OCE)

**Title**: clouddrift, a Python package to accelerate the use of Lagrangian data

**Abstract**: Clouddrift, a Python package, was developed through a grant from the now-defunct National Science Foundation EarthCube program. In the words of NSF, this program “has been transforming the conduct of geosciences research by developing and maintaining a well-connected and facile environment that improves access, sharing, visualization, and analysis of data and related resources.” In this presentation, I’ll introduce the primary functionalities of clouddrift, a Python package designed to expedite the utilization of Lagrangian data in atmospheric, oceanic, and climate sciences. Currently, clouddrift serves as a library of freely accessible Lagrangian datasets and a collection of functions for manipulating and conducting scientific analyses on any Lagrangian datasets. I’ll explain the rationale behind the chosen data structure and its implications for the library’s structure. Additionally, I’ll share some valuable lessons learned from this open-source project funded through a grant.
