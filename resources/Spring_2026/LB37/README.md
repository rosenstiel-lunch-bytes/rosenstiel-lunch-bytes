**Speaker**: Philippe Miron (Premera Blue Cross)

**Title**: Retrieval-Augmented Generation

**Abstract**: I’ll be presenting the fundamentals of Retrieval-Augmented Generation (RAG) and demonstrating a proof-of-concept application designed to answer questions about Lewis Carroll's classic, Alice’s Adventures in Wonderland. We'll walk through building a simple vector store, explore how to leverage LlamaIndex for query retrieval, and showcase Streamlit as a tool for quickly creating an interactive interface. The session will conclude with a discussion on recent advancements and optimizations in RAG.

**Where**: MSC 343 (Rosenstiel Campus)
