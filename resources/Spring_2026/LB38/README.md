**Speaker**: Susan Harrison (OCE)

**Title**: Python workflows using abstractions and Xarray

**Abstract**: Efficiently writing and reusing past-written code is a skill developed with practice. Applying the basics of abstraction allows a coder to produce the same results with fewer lines of newly written code. Increasing familiarity with the methods covered in the lunch byte will improve intuition for how scripts are organized, making code writing both smoother and more enjoyable. You will see examples for how to reduce multi-step transformations using .pipe(), simplify accessing data saved in multiple separate files using Dask, and eliminate avoidable use of for-loops using Xarray. Xarray DataSets are intended to make your code more understandable through labels set only once as data attributes. The labeled attributes create functionality for label-based indexing. This is also useful for grouping data parameters by type and/or time for statistical analysis, and making clean labeled plots with only a single line of code.
