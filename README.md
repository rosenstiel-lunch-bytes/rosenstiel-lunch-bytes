# Lunch Bytes at Rosenstiel

Lunch Bytes is a computing seminar series that provides an informal forum for students,
researchers, and faculty at the Rosenstiel School to discuss and exchange knowledge on
various computing topics, tools, and programming languages.

## Where and when

MSC 343, Fridays at 12 pm.

## Presenter guidelines

* Any format welcome! Slides, live coding, whiteboard, or just your voice.
* 45 minutes or shorter.
* Feel free to ask us for feedback!

## Contributing

Please create a folder for your seminar under `sessions/<Season>/` and upload any contents
(e.g. slides (PDFs can be read on GitHub), code, environment files) along with a README file
(speaker, title, abstract, when, where).
